# 收款码图片放置说明

开屏赞赏页（`donate.html`）需要两张你的收款码图片，放在本目录 `wd_repo/assets/`：

| 平台 | 文件名 | 格式 | 建议尺寸 |
|------|--------|------|----------|
| 微信 | `wechat-pay-cropped.png` | PNG（透明背景最佳） | ≥ 240×240 |
| 支付宝 | `alipay.jpg` | JPG | ≥ 240×240 |

## 怎么放
1. 在微信/支付宝里导出你的收款码图片；
2. 按上表**文件名**保存到本目录（文件名必须完全一致，否则页面仍显示「待上传」占位）；
3. 推送到 `white-dashbord` 仓库即可生效（`git add assets/ && git commit && git push`）。

## 注意
- 图片缺失时页面不会破图，而是显示「收款码待上传」引导卡（带文件名 + 建议尺寸）。
- 不要放伪造/示例二维码——那扫了收不到钱。请放你自己的真实收款码。
- SVG 不被 `object-fit: contain` 直接支持，请用 PNG/JPG。
